# 解法比較の文献レビュー

TSP・ATSP・JSSP・ナーススケジューリングの4問題について、数理計画法（MIP / CP / 分枝カット / 分枝価格法）、メタヒューリスティクス、専用ヒューリスティクス、機械学習系の解法を比べた論文と既存ベンチマークの調査結果です（2026-10-25 時点）。

- 本文: [`index.html`](index.html)（ブラウザで開くか、GitHub Pages で `docs/literature/` として閲覧できます）

## 内容

- 問題ごとの標準インスタンス集、代表ソルバー、主要な比較研究と結果
- 手法×問題の現状マトリクス
- 比較の中立性に関する注意点（提案者バイアス、計算資源の正規化、ソルバー版、インスタンス分布、指標、統計検定、定式化の影響など）
- 手元ベンチマークへの示唆（インスタンスと候補ソルバー、文献の空白）
- 文献リスト（約25件）

## 要点

| 問題 | 現状 |
|---|---|
| TSP | 厳密解は Concorde、近似解は LKH と EAX 型 GA が最強クラス。ニューラル解法は小規模の一様乱数インスタンス以外では品質で及ばない |
| ATSP | 厳密解は加法的限界の分枝限定法・分枝カット、近似解はパッチング系と LKH。同じ条件での最近の横断比較は見つからなかった |
| JSSP | 汎用ソルバーでは CP（CP Optimizer, CP-SAT）が MIP を明確に上回る。最良既知解の更新はタブーサーチ系 |
| ナース | MIP 系（分解・分枝価格法）とメタヒューリスティクスが拮抗。分枝価格法が INRC-II 4週の全20件で最適性を証明（2024） |

原典の要旨しか確認できなかった項目は、本文中で「未確認」と明記しています。
