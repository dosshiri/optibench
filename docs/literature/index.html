組合せ最適化 解法比較レビュー

巡回セールスマン問題（TSP・ATSP）とその時間枠付き版（ATSP-TW）、ジョブショップスケジューリング（JSSP）、ナーススケジューリングについて、これまでの論文や公開ベンチマークで、どの解法が強いと報告されているかを調べました。問題ごとにページを分け、標準的なベンチマーク問題、代表的なソルバー、主な比較研究とその結果をまとめています。

問題ごとの要点

問題名を選ぶと、その問題のページに進みます。

TSP

厳密解は Concorde（分枝カット）が事実上の標準で、汎用MIPソルバーは大きく劣ります。近似解では LKH と EAX型GA が最強クラスです。ニューラル解法は小規模・一様乱数インスタンス以外ではまだ品質で及びません。

ATSP

専用の比較研究は少なめです。厳密解は加法的限界の分枝限定法や分枝カット、近似解はサイクルカバー・パッチング系と、対称化変換したうえでの LKH が中心です。インスタンスの構造によって勝者が変わるのが特徴です。

ATSP-TW

厳密解は専用の分枝カット（時間バケット定式化）と動的計画法、近似解は GVNS などのメタヒューリスティクスが強いです。汎用 MIP は中規模まで戦えますが、汎用 CP と OR-Tools Routing は時間枠が厳しいと実行可能解を見つけること自体に苦労します。ニューラル解法は実行不能な解が残ります。

JSSP

汎用ソルバーでは CP（CP Optimizer, CP-SAT）が MIP を明確に上回ります。最良既知解の更新は今も タブーサーチ系が担っています。深層強化学習は CP-SAT との差を縮めていますが、まだ追い越してはいません。

ナーススケジューリング

問題定義が研究ごとに異なるため、INRC-I / INRC-II / Curtois–Qu の共通ベンチマークが比較の基盤です。MIPベース（分解・分枝価格法）とメタヒューリスティクスが拮抗しており、最近は分枝価格法が最適性を証明できる範囲を広げています。

量子・疑似量子アニーリング

問題別ではなく手法の系統のページです。どの装置も問題を QUBO に直して解くため、TSP は都市数の 2 乗の変数が要り、制約は罰金で入れます。量子アニーラ実機で直接解けるのは 10 都市未満、ハイブリッドや疑似量子でも数十都市で最適値から数〜数十 % 離れ、LKH や CP-SAT に大きく劣るのが文献の一致した評価です。

読み方の注意。 以下の数値は各論文の条件（ハードウェア、時間制限、スレッド数、ソルバー版）での結果です。論文間で直接比較することはできません。本ページの数値と結論は原典の要旨・本文の確認に基づき、確認できなかった点はその旨を書いています。

比較の中立性の注意点

既存論文の結果を読むときにも、手元でベンチマークを組むときにも当てはまる論点です。Accorsi, Lodi, Vigo（2022）のガイドラインと上記文献の実験条件から整理しました。

  1. 提案者バイアス提案手法は時間をかけて調整され、比較対象は既定設定か古い版のまま、という非対称がよくあります。Ku–Beck ではチューニングだけでCPLEXが約1.5倍速くなりました。Liu らでもLKHの調整効果は大きいと報告されています。
  2. 計算資源の正規化スレッド数（CP-SATは4コアで大規模の最適到達が0件から7件に増加）、GPUとCPU、学習時間を含めるかどうかで結論が変わります。単一スレッドを基準にし、並列は別枠で報告するのが無難です。
  3. ソルバー版CP-SAT は2019年の評価から大幅に改良されています。文献値を引用するときは必ず版を併記してください。
  4. インスタンス分布ニューラル解法の多くは一様乱数で学習・評価されていて、クラスタ型や実問題では大きく劣化します。標準インスタンス集と、実務に近い分布の両方を含めるべきです。
  5. 指標の選び方最良既知解とのギャップ、最良値か平均値か、目標解到達時間、厳密解法の場合は最終改善時刻や primal integral。乱択手法は10回以上の試行で平均とばらつきを示します。
  6. 統計検定と集計インスタンス単位の対応ありの検定（Wilcoxon 符号順位検定 + 多重比較補正）と、性能プロファイル（Dolan–Moré）を使います。平均ギャップだけでは少数の外れ値に引きずられます。
  7. 定式化の影響同じMIPソルバーでも定式化によって大差がつきます（JSSPのManne型と時間添字型、ATSPのDFJとMTZ）。「MIP対CP」は「定式化+ソルバー対定式化+ソルバー」の比較だと明示します。
  8. 目的の違い厳密解法は最適性の証明にほとんどの時間を使い、良い解は早く見つけていることが多いです。時間制限つきの品質比較では不当に不利になるため、可能なら「いつ見つけたか」も記録します。
  9. 商用ライセンスとベンチマーク公開一部の商用ソルバーには、ベンチマーク結果の公開に制限がある場合があります。公開する前に各ライセンス条項を確認してください。

手元ベンチマークの組み方

文献で手薄な部分と、再現しやすいソルバーを組み合わせた候補です。問題ごとに「厳密」「汎用ソルバー」「専用ヒューリスティクス / メタヒューリスティクス」「機械学習」から最低1つずつ選ぶと、文献の空白を埋めやすくなります。 問題ごとの候補は、各問題のページの「手元ベンチマークへの示唆」にあります。
