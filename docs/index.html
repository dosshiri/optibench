手法選びの早見表

各問題で最初に試す手法の一覧です。計測結果と論文の両方にもとづく目安で、詳しい根拠は考察の各章にあります。

問題まず使う条件によって切り替える避けたい使い方
TSPLKH業務制約があれば OR-Tools Routing。数百ノードまでで証明が要れば MIP（初期解つき）大規模での CP-SAT、初期解なしの MIP、QUBO 系のアニーリング
ATSPLKH証明が要れば MIP と CP-SAT の両方を試す2-opt 中心の自作局所探索、QUBO 系のアニーリング
ATSP-TWPyVRP自作するなら GVNS。即答が必要なら締め切り順 + 局所探索。70 地点ほどまでで証明が要れば CP-SAT（複数スレッド）時間枠の厳しい問題での OR-Tools Routing、big-M の MIP
VRPTWPyVRP時間枠がそろって狭く証明が要れば MIP か CP-SAT（200 顧客でも可）。自作するなら SISR のような壊して直す探索。OR-Tools で書いてあれば 100 顧客ほどまではそのままでよい時間枠の広い問題での汎用 MIP・CP-SAT、挿入法 + 簡単な局所探索の解をそのまま使う
JSSPCP-SAT（複数スレッド）専用近傍を実装できればタブーサーチ。即答が必要ならディスパッチングルールbig-M の MIP、1 スレッドの CP-SAT、QUBO 系のアニーリング
ナースMIP大規模で MIP が解を出せなければ CP-SAT（複数スレッド）調整なしの汎用 SA、1 スレッドの CP-SAT

量子・疑似量子アニーリング（QUBO 系）は、QUBO に載る数十都市の TSP でも LKH・MIP に届きませんでした（手元の CPU で動く OpenJij・dwave-samplers で平均 45〜74%）。根拠は考察の量子・疑似量子アニーリングの章にあります。

早見表に出てくる手法

各手法の考え方をひとことで説明します。問題ごとに実際に動かした実装の説明は、考察の各章の「比べた手法」と手元ベンチマークの「手法の解説」にあります。

LKH
Helsgaun による巡回セールスマン問題の専用ヒューリスティクス。Lin–Kernighan 法を発展させ、複数の辺をまとめて入れ替える強力な局所探索で、近似解では最強クラス。後継の LKH-3 は時間枠などの制約付きの問題も扱える。
PyVRP
配送計画のオープンソースライブラリ。解の集団を交叉させ、生まれた子を局所探索で磨くハイブリッド遺伝的探索（HGS）を実装した、最先端の配送計画ソルバー。
OR-Tools Routing
Google OR-Tools の配送計画ソルバー。初期解を作ってから誘導局所探索（GLS）などで改善する。時間枠・容量・複数車両といった業務制約をそのまま書ける汎用性が強み。
GVNS
一般化変近傍探索。解をランダムに崩してから局所探索をかけ、良くならなければ崩す量を増やしていくことで局所最適から抜け出すメタヒューリスティクス。
締め切り順 + 局所探索
時間枠の締め切りが早い順に地点を並べ、地点の付け替えや入れ替えで遅れと移動時間を減らす素朴な方法。一瞬で終わる。
CP-SAT
Google OR-Tools の制約プログラミングソルバー。整数変数と制約（巡回路、重ならない区間など）でモデルを書くと、SAT ソルバーの技術と線形緩和を組み合わせて解き、下界と最適性の証明も出す。複数スレッドで異なる探索を並走させると大きく強くなる。
MIP
混合整数計画。0-1 変数と線形の制約・目的関数でモデルを書き、分枝限定法で解く。ここではオープンソースの HiGHS を使った。最適性を証明できるが、big-M のように緩和が弱い定式化では大きな問題が苦手。
SISR（壊して直す探索）
今の解から近くにいる顧客の連なりをまとめて抜き（壊す）、抜いた顧客を貪欲に入れ直す（直す）ことを繰り返し、焼きなまし法の基準で受け入れるメタヒューリスティクス（ruin and recreate）。仕組みが単純で、制約は挿入の可否の判定に書けばよいので、自前の実装に向く。
挿入法 + 局所探索
顧客を 1 人ずつ、距離の増え方が最も小さく制約を守れる位置へ入れて経路を作り、顧客の移動や経路の後半の交換で改善する素朴な方法。一瞬で終わる。
タブーサーチ
近傍で最も良い解へ移り続け、直前の操作を一定期間禁じて逆戻りを防ぐメタヒューリスティクス。JSSP ではクリティカルパス上の作業を入れ替える専用の近傍（N5）を使う。
ディスパッチングルール
機械が空くたびに、処理時間が短い順（SPT）や残り作業が多い順（MWKR）などの規則で次の作業を選ぶ方法。一瞬で解が出るが、品質は低め。
量子・疑似量子アニーリング（QUBO 系）
問題を QUBO（0/1 変数の二次式）に直し、量子アニーラや、それを古典計算機で模した疑似量子アニーリング・焼きなまし法でエネルギー最小の解を探す手法の系統。制約は罰金として目的関数に足す。TSP では変数が都市数の 2 乗になるため、扱えるのは数十都市まで。ここでは手元の CPU で動く OpenJij と dwave-samplers を比べた。
SA（焼きなまし法）
ランダムな変更を、悪くなる場合も「温度」に応じた確率で受け入れ、温度を下げながら局所最適を抜け出す汎用のメタヒューリスティクス。問題に合った近傍と温度の調整が要る。
